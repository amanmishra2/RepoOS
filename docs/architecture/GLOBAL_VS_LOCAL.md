# Global versus local

## User-global

Only universal preferences and explicitly approved reusable Codex assets belong here. RepoOS `0.1.0` does not install or change them.

## RepoOS-owned

Schemas, CLI behavior, neutral fixtures, component contracts, redacted registry/report formats, and accepted cross-project decisions.

## Overlay-owned

Only versioned components with deterministic eligibility, two confirmed consumers, owner, tests, migration, and rollback. No real overlay exists yet.

## Repository-owned

Product behavior, architecture, business rules, data policy, commands, secrets, local instructions, unadopted paths, and explicit exceptions. Unknown ownership is local.

The authoritative rules are [FILE_OWNERSHIP_MODEL.md](../implementation/FILE_OWNERSHIP_MODEL.md).
