# Repository-specific exceptions

This public report uses aliases and intentionally omits private identifiers.

## Local authority that RepoOS must preserve

- **P02:** local-first storage and project-specific scraping/validation boundaries; its nested project has separate package and verification conventions.
- **P04:** evidence-preserving financial data workflows, conservative source policy, offline tests, and sensitive-data exclusions. Resolve P04-A/P04-B scope drift locally.
- **P06:** RepoOS’s current self-hosted runner assumption is not a portfolio default and is being replaced locally.
- **P07:** exact runtime, browser, API, external-ledger, and prohibited-technology constraints; local verification commands remain authoritative.
- **P08:** sole-authority boundary, append-only evidence, provider constraints, issue-key branch convention, ownership manifest rules, and exact product/AgentOps gates.
- **P09 nested project:** no live profile, scraper, cancellation, browser mutation, or other external mutation without explicit approval; sensitive data remains local.
- **P11:** non-Git documentation snapshot; not an automation target.
- **P03, P05, P10, P12, P13:** template, archive, artifact, shared-tooling, or placeholder directories; exclude until explicitly classified and versioned.

## Portfolio rule

RepoOS may distribute only components whose ownership and eligibility are explicit. It must not override stricter repository-local safety, product, data, runtime, or verification constraints. Unknown ownership defaults to repository-owned.
